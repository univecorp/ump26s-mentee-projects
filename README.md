# Unive Mentorship Program Projects

Welcome to the official projects repository for the **Unive Mentorship Program - 2026 Summer**!

## Introduction

As part of our commitment to building real-world experience and providing hands-on familiarity with open-source tools, we have planned dedicated projects for each mentee under the Unive Mentorship Program. This repository serves as the central hub containing all student project repositories.

> By using, cloning, forking, or referencing this repository, you acknowledge and consciously agree to open-source all data and code contained within it. **Please ensure you do not include any sensitive, personal, or private credentials/data in this repository.**

---

## For Mentees Only: How to Use This Repository

Follow the step-by-step instructions below to set up your workspace, complete your tasks, and submit your project.

### Step 1: Fork the Repository

To work on your assigned project, you first need to create your own personal copy (fork) of this repository.

1. Navigate to the main repository page on GitHub.
2. Locate the **Fork** button in the top-right corner of the page (next to the Star button).
3. Click the **Fork** button.
4. Under *Owner*, select your personal GitHub account.
5. Uncheck the box that says "Copy the `main` branch only" if you need all branches, or leave it as default.
6. Click **Create fork**.

*(You now have an independent copy of the repository under your personal GitHub account.)*

---

### Step 2: Complete Your Project Tasks

1. Clone your newly forked repository to your local machine from you *personal GitHub Account*:
```bash
git clone https://github.com/YOUR-USERNAME/Unive-Mentorship-Projects.git
```
2. Please maintain the specific project directory structure and follow the instructions and requirements outlined in your **Project Requirement Book**.
3. Implement your changes, test your code locally, and commit your progress regularly:
```bash
git add .
git commit -m "feat: complete task requirements for project"

```



---

### Step 3: Push Changes to Your Forked Repository

Once you have successfully completed all your tasks, push your local commits back up to your remote forked repository on GitHub:

```bash
git push origin main

```

---

### Step 4: Create a Pull Request (PR)

To submit your project for review, you must open a Pull Request targeting the main repository.

1. Go to your forked repository on GitHub.
2. Click on the **Pull requests** tab near the top of the page.
3. Click the green **New pull request** button.
4. Ensure the base repository is set to the original **Unive Mentorship Program** repository (`main` branch) and the head repository is set to your forked repository (`main` branch).
5. Review your changes in the diff view below to make sure everything looks correct.
6. Make sure to add the relevant issue to the Issue field
7. Click **Create pull request**.
8. Provide a clear and descriptive title and summary of your work (e.g., *Submission: Mentee Project - [Your Name]*), then click **Create pull request** again to finalize your submission.
